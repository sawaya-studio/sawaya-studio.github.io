# 手順

**中身を直したいときに、上から順にやること。**
書ける部品の一覧は [_書き方.md](_書き方.md)、site 全体の作りは [../README.md](../README.md)。

---

## いちばん短い手順

**`preview.bat` をダブルクリックするだけです**（Mac / Linux は `./preview.sh`）。
作り直し・サーバ・ブラウザが一度に立ち上がります。

あとは `content/` の `.md` を書いて保存するだけ。保存するたびに作り直され、
`http://127.0.0.1:5199/` を読み直せば反映されています。

保存すると**ブラウザが勝手に読み直します**。止めるときは、Windows なら開いた 2 つの黒い窓を閉じる、Mac なら `Ctrl+C`。

自分で打つなら、窓を 2 つ開いてこうです。

```
npm run watch     （= node tools/build.mjs --watch）
npm run serve     （= node tools/serve.mjs）
```

書き終わったら、**最後に一度だけ**下の「確かめる」をやってください。

---

## 1. どこを直すか

| 直したい頁 | 開くファイル |
|---|---|
| `/`（sawaya studio） | `content/index.md` |
| `/recaday/` | `content/recaday/index.md` |
| `/telop-studio/` | `content/telop-studio/index.md` |
| `/recaday/closed-test/` | **`.md` はありません。** `recaday/closed-test/index.html` を直に |

`content/` の並びが、そのまま URL になります。`_` で始まる `.md` は頁になりません
（この手順書もそうです）。

新しい頁を足したいときは、`content/` の下に `.md` を作って、頭に

```
---
theme: works        works / recaday / telop のどれか
title: 頁の名前
description: 検索結果と SNS に出る一行
---
```

と書けば、それだけで頁になります。

## 2. 見ながら書く

**Windows** … `preview.bat` をダブルクリック。

**Mac / Linux** … はじめの 1 回だけ実行できるようにしてから、以降は打つだけです。

```
chmod +x preview.sh     ← はじめの 1 回だけ
./preview.sh
```

どちらも 3 つが一度に立ち上がります。**作り直し・サーバ・ブラウザ。**

**止め方は 2 つで違います。**

| Windows | 開いた 2 つの黒い窓を閉じる（それぞれ `Ctrl+C` でも可） |
| Mac / Linux | `Ctrl+C` **ひとつで両方落ちます** |

Windows で窓を分けているのは、**作り直しのほうが「書体に足りない字がある」などを
教えてくる**ためです。サーバの記録に混ぜると読み落とします。

自分で打つなら、窓を 2 つ開いてこうです。

```
npm run watch     （= node tools/build.mjs --watch）
npm run serve     （= node tools/serve.mjs）
```

`--watch` は `content/` と `themes/` を見ていて、**保存するたびに作り直します。**
`serve` は `http://127.0.0.1:5199/`。

**保存すると、ブラウザが勝手に読み直します。** 自分で更新を押す必要はありません。

### いつ、何が起きるか

```
.md を保存
   ↓  ためる 120ms（保存が 2 回起こることがあるため）
build --watch が、頁ぜんぶを作り直す        → .html と assets/*.css が書かれる
   ↓  ためる 150ms（1 回の作り直しで何度も書かれるため）
serve が、ブラウザに「読み直せ」と知らせる
   ↓
画面が変わる
```

**保存から画面まで、実測でおよそ 0.3 秒**です。

**見ているもの**

| `content/` | 中身。**保存で作り直します** |
| `themes/` | 見た目と部品。同じく |
| `site.json` | site の名前と URL。同じく |

**見ていないもの（自分でやること）**

| 書体を絞り直す | `node tools/subset-fonts.mjs`（build が「足りない」と教えます） |
| ロゴ・アイコン・雲を焼き直す | `py -3.14 tools/make-logo.py` など |
| `tools/` を直したとき | `--watch` を一度止めて、開き直してください |

**これは手元で見るときだけの仕掛け**です。ブラウザへ知らせる小さな script は、
サーバが返すときに差しこんでいるだけで、**出来上がったファイルには入りません。**

## 3. 作り直す

`--watch` を使っていないときは、これだけです。

```
npm run build     （= node tools/build.mjs）
```

---

## 4. 書体を絞り直す（**見出しに新しい字を使ったとき**）

書体は「その頁に出てくる字だけ」に絞って同梱しています。
**新しい字を使うと、そこだけ別の書体で出ます。**

作り直したときに `build.mjs` が教えてくれるので、言われたらこれを走らせます。

```
node tools/build.mjs         ← 先に頁を作ってから
node tools/subset-fonts.mjs  ← 絞り直す
node tools/build.mjs         ← もう一度（数え直すため）
```

言われるのはこういう形です。

```
! M PLUS 1 に無い字が 3 個あります: 鬱蠡黌
  **そこだけ別の書体で出ます**（黙って起こります）。絞り直してください:
    node tools/subset-fonts.mjs
```

要るもの（初回だけ）:

```
py -3.14 -m pip install fonttools brotli uharfbuzz
```

---

## 5. ロゴを焼き直す（**名前や字間を変えたとき**）

sawaya studio のロゴは、書体を読ませずに**図として焼いて**あります。

```
py -3.14 tools/make-logo.py
```

触るのは `tools/make-logo.py` の頭にある 4 つです。

| `TEXT` | 焼く字（いまは `sawaya studio`） |
| `WEIGHT` | 太さ（100〜900。いまは 600） |
| `TRACKING` | 字間ぜんたい（em の千分率。いまは 90） |
| `PAIRS` | 対ごとの詰め（負で詰める） |

大きさだけ変えたいときは、焼き直さずに
`themes/works/style.css` の `.logo svg` の `width` を触ります。

---

## 6. タブのアイコンを焼き直す

```
py -3.14 tools/make-icon.py
```

  `assets/sawaya-studio-icon.svg` / `.png` … Saira の `s` を、濃い地に白で
  `assets/recaday-icon.png` … recaday の `logo-r.png`（白い R）に、7:00 の空を敷いたもの

頁に付けるのは front matter の 1 行です。

```
icon: /assets/sawaya-studio-icon.svg        タブのアイコン
appleIcon: /assets/sawaya-studio-icon.png   ホーム画面に置いたとき（省くと icon と同じ）
```

**16px で見えるものしか置かないこと。** ワードマークはタブの大きさでは読めません。
**濃い地に薄い字**にしてあるのは、タブの地が明るいことも暗いこともあるからです。

## 8. 確かめる

`node tools/build.mjs` が、作り直すたびに 3 つを数えます。
**どれも黙って壊れるたぐい**なので、出たら必ず直してください。

| 指した先が無い | 絵や書体が出ません |
| 根から書いた道が残っている | `http://` では通りますが、**ファイルを直接開くと壊れます** |
| 書体に足りない字がある | そこだけ別の書体で出ます |

そのうえで、**この 2 つの開き方で見てください。**

1. `http://127.0.0.1:5199/`（`node tools/serve.mjs`）
2. **`index.html` をダブルクリックして直に開く**

2 のほうが大事です。**サーバ経由では通るのに、直接開くと壊れる**という不具合を、
ここまでに 2 回出しています（空の雲が出ない／書体が system のものに落ちる）。

## 9. 公開する（**まだやっていません**）

いまは手元にあるだけです。公開すると決めたら、この順です。

```
git add -A
git commit -m "何をしたか"
gh repo create SawayaWorks/sawayaworks.github.io --public --source=. --push
```

そのあと GitHub の設定で Pages を有効にします（Settings → Pages → Branch: `main` / `/`）。
数分で `https://sawayaworks.github.io/` に出ます。

2 回目からは、これだけです。

```
node tools/build.mjs
git add -A
git commit -m "何をしたか"
git push
```

**出来上がった `.html` も git に入れてください。** GitHub Pages は `.md` から
作り直してくれないので、**手元で作ったものをそのまま置く**形にしています。

## よくある詰まり

**「5199 番はもう使われています」と出る**

たいていは、**前に立ち上げたサーバがまだ動いているだけ**です。
そのまま `http://127.0.0.1:5199/` を開けば見られます。

窓が見つからなくて止めたいときは、こうです。

```
Windows   netstat -ano | findstr :5199     ← いちばん右の数字が番号
          taskkill /F /PID <番号>

Mac       lsof -ti :5199 | xargs kill
```

**`./preview.sh` を `Ctrl+C` 以外で止めたとき**に起きやすいです
（`Ctrl+C` ならサーバも一緒に落ちます）。

**`./preview.sh: Permission denied` と出る**

はじめの 1 回の `chmod +x preview.sh` がまだです。

**`bad interpreter: /bin/sh^M` と出る**

`.sh` の改行が CRLF になっています。`.gitattributes` で LF に保つようにしてあるので
ふつうは起きませんが、エディタで保存し直したときに起こることがあります。
改行を LF にして保存し直してください。

**直したのに古いものが出る**

公開したあとに起きます。`Ctrl+Shift+R` で読み直してください。
手元で見ているあいだは起きません（`serve.mjs` が「貯めるな」と言っています）。

**ファイルを直接開くと、空や書体が出ない**

根から書いた道（`/assets/…`）が残っています。
`node tools/build.mjs` が数えて止めるので、言われたところを直してください。

**`:::` を書いたのに、そのまま字で出てしまう**

直前の `<!-- -->` のあとに空行が無いか、`:::` の閉じが足りていません。
`:::` は開いた数だけ閉じます。

**表が表にならない**

`|` で始まる行が続いていないと、表になりません。
見出しの無い表（`|---|` を書かない形）は、**1 列目が見出しになります。**
