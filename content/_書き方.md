# 書き方

`content/` の下の `.md` を書けば、頁ができます。この頁自体は `_` で始まるので、
site には出ません（`_` で始まる `.md` は作られない）。

```
node tools/build.mjs            作り直す
node tools/build.mjs --watch    直したら、そのつど作り直す
node tools/serve.mjs            http://127.0.0.1:5199/ で見る
```

`content/` の並びが、そのまま URL になります。

| `content/index.md` | `/` |
| `content/recaday/index.md` | `/recaday/` |
| `content/telop-studio/index.md` | `/telop-studio/` |

**`recaday/closed-test/` だけは、ここから作っていません。** 手で書いた頁のままです。

---

## 頁の頭（front matter）

```
---
theme: recaday          どのテーマで組むか（recaday / telop / works）
lang: ja
title: recaday          タブと検索結果に出る名前
description: …          検索結果と SNS に出る一行
image: /assets/…png     SNS に出る絵（省いてよい）
icon: /assets/…png      タブのアイコン（省いてよい）
appleIcon: /assets/…png ホーム画面に置いたときのアイコン（省くと icon と同じ）
draft: true             書きかけ。付けているあいだは作られない
---
```

長い文は `>` で折り返せます。

```
description: >
  ここに長い一行を
  何行かに分けて書ける
```

## 文章

ふつうの Markdown です。

```
# 見出し     ## 中見出し     ### 小見出し
ふつうの段落。
- 箇条書き
1. 番号つき
> 引用
---
| 表 | です |
|---|---|
| あ | い |
**太字**  *斜体*  `字面`  [名前](行き先)  ![説明](絵)
```

見出しの無い表（`|---|` の行を書かない）は、**1 列目が見出しになります**。

生の HTML もそのまま通ります。部品では足りないときに使ってください。

---

## 部品（`:::`）

```
::: 名前 属性=値 属性="間の空いた値"
中身（Markdown のまま書ける）
:::
```

入れ子にできます。閉じるのは `:::` だけ。

中身が `[` か `{` で始まっていたら、**文章ではなく「値」**として読みます（JSON）。
並びを渡す部品はこちらです。

属性の名前に `:ja` / `:en` を付けると、**言葉ごとの値**になります。

```
::: frame time=07:41 caption:ja="始発、まだ静か" caption:en="First train"
:::
```

知らない名前を書くと、その名前がそのまま class になった `<div>` になります。

## recaday のテーマで使えるもの

| `::: hero` | 名前だけで 1 画面。`label:ja` `label:en` で下の合図の字、`href` で飛び先 |
| `::: body` | 読むところの入れ物。板はこの中に並べる |
| `::: plate` | ガラスの板。1 つの話につき 1 枚 |
| `::: ja` / `::: en` | 言葉。**両方を組んでおいて、片方を伏せる** |
| `::: eyebrow` | 見出しの上の小さな行 |
| `::: note` | 小さい字の注意書き |
| `::: tick` | 印つきの箇条書き（中に `- ` を書く） |
| `::: chips` | 札の並び（中に `- ` を書く） |
| `::: cols` | 2 列に並べる |
| `::: frame` | 焼き込みの枠 1 枚 |
| `::: phone` | カメラ画面の見立て（縦） |
| `::: player` | 焼き込みの見本を流す（値で渡す） |
| `::: fonts` | 時刻の書体を選ぶ口 |
| `::: filters` | フィルターを選ぶ口 |
| `::: joiner` | つないで一本にする図（値で渡す） |
| `::: act` | 押す口（`href`） |
| `::: closing` | しめの板 |
| `::: footer` | 下の帯 |

### `::: frame` の属性

| `scene` | `dawn`（朝の駅）/ `room`（窓のある部屋）/ `park`（公園） |
| `font` | `bold` `thin` `retro` `digital` `serif` `round` |
| `time` | 焼き込む時刻（`07:41`） |
| `filter` | `none` `skin` `vivid` `bright` `sepia` `mono` `bold` `binary` |
| `caption:ja` / `caption:en` | 下に出る一言 |
| `sceneId` | `filter-scene` にすると、`::: filters` の掛かる先になる |

**比率はアプリと同じ**です（`src/theme.ts` の `clockStyle` と `CLOCK_FONTS`）。
数字の高さを固定してあるので、書体を替えても時刻の大きさは変わりません。

### `::: player` の値

`[ 撮った時刻, 背景, 日本語, 英語 ]` を並べます。

```
::: player
[
  ["07:12:40", "dawn", "始発、まだ静か", "First train"],
  ["07:41:50", "room", "窓、あけた", "Opened the window"]
]
:::
```

時刻は「撮影開始の実時刻 + 再生位置」で進みます。**アプリの数え方と同じ**です。

### `::: joiner` の値

`[ 時刻, 日本語, 英語 ]` を並べ、`result:ja` / `result:en` に最後の一行を書きます。

## テロップスタジオのテーマで使えるもの

| `::: topbar` | 上の帯。`brand` `lead` `pill` |
| `::: main` | 骨格 |
| `::: hero` / `::: section` | 節。`id` で名前を付けると `#` で飛べる |
| `::: eyebrow` | 見出しの上の小さな行 |
| `::: lead` | 見出しの下の 2〜3 行 |
| `::: note` | 小さい字 |
| `::: chips` | 札の並び（**オレンジ＝押せない**） |
| `::: cta` / `::: btn` | 押す口（**緑＝押せる**）。`href`、`ghost` で白い方 |
| `::: cols` / `::: card` | 紙のカードを並べる |
| `::: spec` | 表。狭い画面で横に巻けるようにする |
| `::: editor` | さわれる画面（行の一覧＋右の画面）。値で渡す |
| `::: road` | これから。`now=` が「いまここ」 |
| `::: footer` | 下の帯 |

### `::: editor` の値

```
::: editor speakers="わたし:#2fa45f, ゲスト:#f2913c" pos=7 note="※ うしろの絵は見本です。"
[
  {"kind":"speech","at":"0:04.0","who":0,"text":"ここにセリフ"},
  {"kind":"gap","at":"0:10.6","len":0.4},
  {"kind":"telop","at":"0:11.0","text":"ここにテロップ"},
  {"kind":"se","at":"0:12.4","file":"ぽん.wav","hint":"この時刻に1回鳴る"}
]
:::
```

| `kind` | `speech` / `gap` / `telop` / `text` / `se` / `bgm` |
| `at` | その行の時刻 |
| `who` | 誰が喋ったか（`speakers` の何番目か） |
| `cut` | `true` にすると、書き出しから落ちた見た目になる |
| `len` | `gap` の長さ（秒）。長いと色が変わる |
| `pos` | テロップを最初に置く場所（0〜8。左上から右下へ） |

**色の決まりを崩さないこと。** 緑は押せるものだけ、オレンジは押せないものだけです。

## Sawaya Studio のテーマで使えるもの

**見た目はまだ決まっていません。** 中身を置ける形だけ用意してあります。

| `::: main` / `::: top` / `::: section` | 骨格 |
| `::: mark` | 小さい名乗り |
| `::: eyebrow` | 節の名前 |
| `::: note` | 小さい字 |
| `::: chips` | 札の並び |
| `::: works` | 作ったものの一覧。値で渡す |
| `::: links` | 連絡先。値で渡す |
| `::: footer` | 下の帯 |

```
::: works
[
  ["recaday", "/recaday/", "一行の説明", "iOS / Android", "#F2D357"]
]
:::

::: links
[
  ["GitHub", "https://github.com/SawayaWorks"]
]
:::
```

## 見た目を直したいとき

`.md` ではなく `themes/<名前>/` を直します。

| `style.css` | 見た目。**頁の中に丸ごと埋まる** |
| `page.js` | 動くところ。同上 |
| `theme.mjs` | 頁の外枠と、`:::` で呼べる部品 |

**css も js も頁の中に埋めています。** 頁は数枚しかなく、どれも 1 回読んで終わりなので、
別ファイルにして往復を増やすより速いためです。共有するのは重いもの（空・雲・書体・絵）だけで、
それは `/assets/` にあります。
